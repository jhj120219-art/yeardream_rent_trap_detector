# AI 월세 함정 탐지기

부동산 광고의 월세·관리비를 공공 데이터로 비교해, 비교 근거와 신뢰도, 확인할 항목을 보여주는 서비스를 만드는 팀 프로젝트입니다. 이 서비스는 사기·부당 여부를 **판정하지 않고** 참고 정보와 확인 질문만 제공합니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| [`backend/`](backend/) | DB·API·서버, 공공 API 수집, 캡처 정보 추출 연동, 입력 검증 |
| [`frontend/`](frontend/) | 화면 설계, 사용자 흐름, 화면 프로토타입 |
| [`machine/`](machine/) | 데이터 분석·추정 모듈(월세 시세 비교, 관리비 공과금 참고값), 입력 이미지·문구 판독 실험, 검증 기록 |

각 폴더는 담당자가 독립적으로 관리하며, 이 메인 페이지에는 README만 둡니다.

## machine 폴더 소개

- **월세 시세 비교 분석 모듈** — 서울시 전월세 실거래 데이터로 유사 거래를 찾아 가격 위치와 신뢰도를 계산합니다. 연동 규격은 `machine/api_spec.md`, `machine/contract/` 를 확인하세요.
- **관리비 공과금 참고값(실험 중)** — 광고 관리비에 포함될 수 있는 전기·수도·가스·인터넷을 통계(가구에너지패널)와 공식 요금표로 계산한 참고 금액을 보여줍니다. 코드는 `machine/analysis_internal/utility/`, 시험판 화면은 같은 폴더의 `demo/`에 있습니다.
- **광고 이미지·문구 판독 실험** — OCR·VLM 비교와 규칙 파서는 `machine/analysis_internal/extraction/` 에 있습니다.
- **검증 현황** — 무엇을 어디까지 확인했는지와 아직 주장하면 안 되는 것은 `machine/analysis_internal/utility/검증_현황.md` 에 정리했습니다.

자세한 설명과 실행 방법은 [`machine/README.md`](machine/README.md) 를 보세요.

## 협업 원칙

- 미확인 값은 추정해서 채우지 않고 사용자 확인 또는 판단 보류로 처리합니다.
- API 키·DB 비밀번호·개인 정보는 저장소에 올리지 않습니다(환경변수 사용).
- 공공 데이터 원본과 계약 단위 결과, 실제 광고 캡처는 올리지 않습니다.
- 결과 화면과 문구에는 "부당·과다 청구"처럼 판정하는 표현을 쓰지 않습니다.
