# AI 월세 함정 탐지기 — 분석 담당 사전 확인 (2026-10-18)

근거 자료: ChatGPT 대화 "가스비 전기세 청구 방식"(전세사기 데이터 → 월세 비교 설계 → 유사 매물 1~3차 탐색 → 분석 담당 업무 정리)
확인 방법: 서울 열린데이터광장 `tbLnOpendataRentV`(서울시 부동산 전월세가 정보)를 우리 인증키로 직접 호출, 관악구 2025~2026(85,233건)으로 정제·백테스트.
스크립트: `collect_rent.py`(수집), `analysis_rent.py`(정제 + 유사 거래 탐색 백테스트). 결과: `output/`

## 1. ChatGPT 설계가 데이터로 성립하는가 — 확인된 것
| ChatGPT 주장 | 실제 확인 |
|---|---|
| 서울시 전월세 데이터에 면적·층·건축연도·보증금·월세·용도 있음 | 맞음. 컬럼: RENT_AREA, FLR, ARCH_YR, GRFE, RTFE, BLDG_USG 등 23개 |
| 신규/갱신 계약을 구분해야 함 | 구분 컬럼 `NEW_UPDT_YN` 있음. 관악구 월세 기준 신규 58,076 / 갱신 6,147 / 불명 2,550(정제 후) |
| 서울시 전월세는 2011년부터 누적 | 전체 2,660,991건(전 구·전 연도). 관악구 2025: 59,546, 2026: 25,687건 |
| 동·호수는 공개되지 않음 | 맞음. 건물명(BLDG_NM)도 85,233건 중 45,847건(54%) 비어 있음 → 같은 건물 식별 불가 |

## 2. ChatGPT 설명과 다르거나 보완해야 할 점 (데이터로 확인)
1. **"빌라" 중심 설계는 관악구 현실과 맞지 않음.** 관악구 월세(2025~26) 67,011건 중 **단독다가구 40,049건(60%)**, 연립다세대 10,166건, 오피스텔 9,186건, 아파트 7,610건. 원룸 월세는 단독다가구·오피스텔이 대부분이라 비교 대상을 용도별(단독다가구/연립다세대/오피스텔)로 나눠야 함.
2. **단독다가구는 층(FLR) 값이 전부 0.** 반지하·지상층 구분을 요구한 설계(반지하 혼재 경고)를 단독다가구에는 적용할 수 없음. 음수 층 557건은 다른 용도에 있음.
3. **중복 판정 불가.** 모든 컬럼이 동일한 행이 25,117건(29.5%). 호수·(대부분) 건물명이 없어 "같은 건물 다른 호실의 동일 계약"과 "실제 중복"을 구분할 수 없음 → 삭제하지 말고 중복 의심 플래그만.
4. 월세 0원 8건, 면적 이상 282건, 보증금 0원 260건, 건축연도 결측 2,627건(3.1%).
5. **임대면적 기준이 광고 전용면적과 같은지는 아직 미확인**(ChatGPT도 확인 필요라고 함).

## 3. 유사 거래 1~3차 탐색 백테스트 (기준: 신림동 신규 월세 최근 3개월 2,412건, 계약일 이전 거래만 사용, 비교 10건 이상이면 확정)
조건: 1차(같은 동·면적 ±10%·건축연도 ±5년·보증금 ±30%·12개월), 2차(±20%·±10년·±50%·18개월), 3차(같은 구·면적 ±25%·보증금 ±100%·24개월). 신규 계약만, 같은 용도·같은 지하 여부끼리.

| 용도 | 기준 매물 | 1차 확정 | 2차 | 3차 | 보류 | 중앙 오차율 | 오차 ≤20% | 실제값이 IQR 안 |
|---|---|---|---|---|---|---|---|---|
| 단독다가구 | 1,641 | 94.2% | 5.5% | 0.2% | 0% | 14.6% | 63.5% | 57.0% |
| 연립다세대 | 347 | 61.1% | 36.3% | 2.6% | 0% | **23.5%** | **44.1%** | 53.0% |
| 오피스텔 | 222 | 67.6% | 28.8% | 3.6% | 0% | 10.4% | 70.7% | 52.7% |
| 아파트 | 202 | 74.3% | 22.8% | 3.0% | 0% | 12.0% | 64.9% | 57.9% |
| 전체 | 2,412 | 85.3% | 13.6% | 1.1% | 0% | 15.0% | 61.5% | 56.1% |

- 신림동에서는 보류(비교 10건 미만)가 0%. 데이터 공급은 충분. 단계가 올라갈수록 오차가 커짐(1차 14%, 2차 22%, 3차 30%).
- **"시세 대비 비싸다"를 판정하기엔 오차가 큼.** 중앙 오차 15%, 연립다세대는 23.5%. 월세가 시세 중앙값보다 15~20% 이내로 높은 경우는 데이터만으로 "함정"이라고 말하기 어려움. 중앙값 하나보다 사분위 범위(IQR)를 같이 보여주는 편이 적절(실제값이 IQR 안에 들어오는 비율 56%로 명목 50%와 비슷 → 범위 표시는 대체로 믿을 만).
- 보증금-월세 환산 보정(보증금 차이를 연 4~10%로 월세에 반영): 오차 18.8% → 16.7%(연 4%)로 소폭 개선. 보증금 밴드를 쓰는 지금 방식이 더 낫지만 효과는 작음.
- 한계: 관악구 2025~26만 검증, 한 지역·한 기간. 옵션·관리비·상태는 데이터에 없어 오차의 원인 분리는 못 함. 비교 중앙값은 "호가"가 아니라 "실제 체결 계약" 기준.

## 4. 분석 담당 업무로서의 판단
- ChatGPT가 정리한 3가지(정제, 비교 로직, 검증표·신뢰도) 모두 이 데이터로 진행 가능. 산출물 `clean_rent_data.csv`는 이미 생성(`output/clean_rent_data.csv`, 66,773건).
- 아직 안 한 것: 다른 구, `validation_report.xlsx`, 신뢰도 점수 기준 확정, 광고 전용면적과의 기준 비교, 팀원이 부를 `compare_rent.py` 함수화.
