로컬 시연 · 데이터 분석 파트 · 비교 데이터: 서울 6개 구 신규 월세 실거래

입력한 월세가 주변 실거래에서 어느 가격대인가

광고에서 읽은 값을 입력하면 분석 엔진이 같은 건물 또는 비슷한 조건의 신규 계약을 찾아 가격 위치를 보여줍니다. 강서·관악·광진·노원·동작·마포구만 가능합니다.

이렇게 사용합니다

  1. 광고에서 읽은 값을 입력합니다. 지역, 건물 유형, 면적, 보증금, 월세는 필수이고, 지번을 알면 같은 건물의 과거 거래와 먼저 비교합니다.
  2. 엔진이 비교 거래를 찾습니다. 지번이 확인되면 같은 건물, 아니면 같은 동에서 면적·보증금·준공연도가 비슷한 최근 신규 계약을 찾고, 부족하면 조건을 넓힙니다.
  3. 가격 위치와 근거를 보여줍니다. 입력한 월세가 비교 거래의 어느 가격대인지, 몇 건을 근거로 했는지, 신뢰도는 어떤지 함께 표시합니다. 근거가 약하거나 값이 의심스러우면 판정하지 않고 이유를 알려줍니다.

결과 읽는 법

  • 파란 구간 비교 거래의 중간 50% 가격대입니다. 검은 선이 입력한 월세입니다. 분홍 구간은 상위 10% 경계 이상입니다.
  • 판정 라벨 낮은 편 · 중간 범위 · 다소 높은 편 · 상위 가격대 중 하나이며, 모두 유사 거래와 비교한 위치일 뿐 바가지나 사기 판정이 아닙니다.
  • 신뢰도 높음·보통·낮음 비슷한 조건에서 중앙값의 오차가 20% 이내였던 비율이 높았는지를 뜻합니다. 낮음이면 위치만 참고로 보여줍니다.
  • 판정 보류 근거가 약함, 월세가 5%만 달라도 라벨이 바뀌는 경계, 값이 시세에서 크게 벗어남(자릿수 오독 의심), 층·면적 기준 미확인 중 하나입니다.

시연 순서 추천 (아래 예시 버튼을 순서대로)

  1. ① 같은 건물 지번이 확인된 오피스텔: 같은 건물 거래 171건으로 비교, 신뢰도 높음.
  2. ② 지번 없이 동 단위 같은 값으로 지번만 비우면 비교 범위가 넓어지고 신뢰도와 근거 건수가 달라집니다.
  3. ③ 월세 자릿수 오독 50만원을 500만원으로 잘못 읽은 경우: 판정 대신 입력 확인을 요청.
  4. ④ 단독다가구 층 미확인 반지하 여부를 알 수 없어 지상 확인 전에는 판정하지 않음.
  5. ⑤ 공급면적 입력 전용면적 기준 거래와 비교되지 않아 판정하지 않음.

광고 정보 입력

전용면적 기준 (단독다가구는 계약면적)
단독다가구는 지상 확인이 있어야 판정
입력하면 같은 건물 비교(0단계) 시도

분석 결과

비교 거래의 중간 50% 범위 (Q25~Q75)상위 10% 경계(Q90) 이상입력한 월세

    비교 대상은 실제 체결된 신규 계약이며, 광고 월세가 적정한지의 정확도를 보장하지 않습니다. '상위 가격대'는 유사 거래와 비교한 위치이고 바가지·사기 판정이 아닙니다. 평균 월세 오차는 약 17만원입니다. 입력값은 이 PC 안에서만 처리됩니다.
