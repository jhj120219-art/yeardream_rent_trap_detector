# utility — 공과금(전기·가스·수도) 참고 비용 계산 (임시, 로컬)
- `tariffs.py` 단가와 확인 상태(verified), `calc.py` 사용량→요금, `reference.py` 가구에너지패널 14차 서울 결과표 기반 참고 사용량·요금, `test_utility.py` 기본 검증.
- 확인된 값: 한전 주택용 저압 누진 단가·연료비조정(+5원/kWh, 2026Q4), 서울도시가스 22.5268원/MJ, 아리수 가정용 요금(계산기 결과로 검증).
- **확인 필요(가정)**: 기후환경요금(9.0원/kWh 가정), 전력산업기반기금율(3.7% 가정, 2.7%로 안내하는 자료도 있음), 서울가스 기본요금(1,250원/월)과 평균열량(43 MJ/N㎥ 근사).
- 참고 요금은 "서울 가구 평균" 기준이며 가구에너지패널의 주택종류·가구원수·면적 표를 서로 곱하지 않고 관점별로 따로 보여준다. 월별 배분은 서울 전체 월별 프로파일에 조건별 연간 비율을 곱한 가정이다. 도시가스를 쓰지 않는 가구가 평균에 섞여 있어 가스 사용 가구의 실제 값보다 낮을 수 있다.
- 마이크로데이터(승인 대기)가 오면 조건별 분포(Q25~Q75)와 가스 사용 가구 한정 평균으로 교체할 예정.

## 관리비 점검 로직 (`check.py`)
- 상태는 REFERENCE_ONLY / REVIEW_REQUIRED / INSUFFICIENT_DATA 뿐이며 정상·과다를 확정하지 않는다. 관리비 총액-추정합계는 부당 금액으로 해석하지 않는다.
- 항목별 청구액이 있을 때만 비교하고(참고 범위 상한의 1.5배 초과면 추가 확인, 임시값), 가스는 사용 여부·난방 방식이 확인되지 않으면 보류한다.
- `bill_eval_template.csv`: 실제 고지서 20~30건 평가셋 양식(개인정보 제외). 평가 지표: 항목별 절대오차, 계절·유형별 오차, 청구액이 범위에 들어가는 비율, 정상 청구를 과다로 경고한 비율.
- 단가 확인 상태: 기금율 2.7%(한전 요금표 공개 사본·정부 발표 기준, 한전 원문 확인 전 잠정), 서울가스 기본요금 1,250원(요금표 안내), 기후환경요금 9원/kWh(에너지경제연구원 2026-04 보고서에서도 확인, 2026-10 적용 확인은 약관 별표 확인 필요), 열량은 고지서 값 필요.

## 가스 사용 가구 보정 (2026-10-20)
- 가구에너지패널 서울 표본 1,078가구의 주난방연료: 도시가스 917(85.1%), 지역난방 146(13.5%), 전력 15(1.4%).
- 서울 가구당 연간 도시가스: 전체 평균 651.4N㎥(가스 미사용 가구 포함), **도시가스 난방 가구 723.7N㎥(RSE 2.2%)**, 지역난방 가구 171.8(취사용), 전기난방 448.8(RSE 32%, 표본 15라 불안정).
- 결과표 숫자를 임의 비율로 나누지 않고, 난방 방식이 개별 도시가스로 확인되면 '주난방연료별' 표의 도시가스 가구 값을 참고 범위에 추가했다(`check.py`, 가스 항목). 주난방연료가 '도시가스'인 가구에는 중앙난방(관리비로 청구)이 섞여 있어 개별 도시가스와 완전히 같지 않다.
- 한전 요금 계산기와의 교차검증(기후환경요금, 기금 확인)은 한전ON 계산기 화면 조작이 막혀 아직 하지 못했다.

## 사용자 화면 시험판 (`demo/`, 2026-10-20)
- `demo/run_utility_demo.bat` 로 http://127.0.0.1:8766/ 실행. 입력: 달·가구원 수·주택유형·면적·난방 방식·가스 사용·광고 관리비·포함 항목·항목별 청구액(선택), 광고 문구 붙여넣기(규칙 파서).
- 출력: 항목별 **서로 다른 집단 평균 기준 참고 금액(각각)**, 사용량 민감도(전기 ±20%, 가스 ±30%는 가정), 광고 항목 청구액과의 비교(확인 필요 이상 판정 없음), 광고에서 별도로 적은 항목의 참고 금액(겹쳐 더하지 않음), 월별 그래프, 확인 질문, 가정·한계(요금 기준일, 사용량 기준 연도 표시).
- ChatGPT 권고 반영: 집단별 값의 최소~최대를 정상 범위로 표현하지 않고, 총액-추정합계를 부당액으로 표시하지 않으며, 1.5배 기준은 '내역 확인 권장' 이상으로 쓰지 않음. `test_scenarios.py` 로 4가지 상황(총액만 / 포함 항목 / 항목별 금액 / 난방 미확인) 검증.

## 관리비 구성 보기 (2026-10-20, ChatGPT 상의 `gpt_utility_decomp_20261020.txt` 반영)
- 취지: 공용 관리비는 '기타'로 두고, 추정 가능한 개별 사용 항목(전기·수도·가스·인터넷)의 참고 비용만 대입해 광고 관리비가 어떻게 구성되는지 보여주고 고객이 직접 비교하게 한다. 서비스가 판정하지 않는다.
- 분해 종류: NONE(총액만, 분해 안 함) / HOLD(보류) / VIRTUAL(포함 항목+참고 비용 대입, '참고 가정에 따른 나머지 금액') / MIXED(일부 항목만 광고 금액) / ACTUAL(항목별 광고 금액, '광고상 금액 미분류 부분'). 막대는 참고값 중앙을 쓴 가상 배분이며 실제 구성비가 아니다.
- 보류 조건: 총액·포함 항목 없음, 포함 항목 중 가스 사용·난방 미확인, 전기·수도·가스 계량 방식이 세대별 실비가 아니거나 모름(사용자가 '세대별이라고 가정' 가능, 가정임을 표시), 참고 비용이 총액 이상(음수·0으로 자르지 않음).
- 금지 표현: 부당·과다 청구·눈탱이·숨겨진 관리비·실제 공용관리비 비율. 기타 비율의 임계값(70% 등)과 빨간 경고는 쓰지 않음(통계적 근거 없음, 가스 미사용 가구 평균 등으로 비율이 크게 달라짐).
- 기타(공용 관리비) 맥락 자료는 항목 예시와 청년안심주택 공개 예상 관리비 2건(상봉역 20.2㎡ 56,802원, 개봉역 16타입 120,000원)만, 정상 상한이 아닌 건물별 편차 예시로 표시(ChatGPT 조사, 직접 확인 전). 25㎡ 83,000원 사례는 재확인 실패로 제외.
- 고지서 사용량(전기 kWh·수도 ㎥·가스 N㎥)을 넣으면 공식 요금표로 계산한 값을 보여 준다. 테스트 `test_scenarios.py` D1~D10 통과.
