관리비에 들어갈 공과금, 통상 얼마일까

광고의 관리비에 포함된다고 적힌 전기·수도·가스·인터넷을 서울 가구 평균 사용량과 2026년 요율로 계산해 참고 비용을 보여줍니다. 과하다고 단정하지 않고, 광고주에게 확인할 질문을 함께 드립니다.

이 페이지 사용 설명서 (먼저 읽어 보세요)

이 서비스는 부동산 광고에 적힌 관리비 안에 들어갈 수 있는 전기·수도·가스·인터넷을, 서울 가구 평균 사용량과 2026년 요금표로 계산해 참고값으로 보여줍니다. 공용 관리비(청소·경비·승강기 등)는 "기타"로 남겨 두고, 광고주에게 무엇을 확인하면 좋은지 질문으로 정리해 드립니다. 이 금액이 비싸다·부당하다고 판정하지 않습니다.

  1. 예시로 시작하기 — 아래 "예시 시나리오" 버튼을 누르면 입력이 자동으로 채워지고 결과가 나옵니다. 먼저 3개를 차례로 눌러 차이를 보세요.
  2. 내 광고로 해 보기 — 광고 문구(예: "관리비 8만원 수도·인터넷 포함")를 붙여 넣고 "문구로 채우기" → 읽힌 값을 광고 원문과 대조해 고친 뒤 "참고 비용 계산"을 누르세요.
  3. 결과 읽는 법 — ① 광고에서 확인된 사실 ② 통계로 계산한 참고 비용(폭으로 표시) ③ 가정에 따른 가상 나머지 금액 ④ 광고주에게 확인할 질문 순서로 보세요. 가상 구성은 실제 관리비 명세가 아닙니다.
  4. 이런 입력은 계산을 보류합니다 — 포함 항목을 모를 때, 전기·수도가 세대별 실비인지 모를 때, 같은 항목이 포함·별도 양쪽에 선택될 때, 관리비 단위가 이상할 때(월 500만원 초과).

이미지(캡처) 입력은 연구 중입니다. 이 시험 페이지에는 아직 연결하지 않았고, 연결하더라도 읽힌 값은 반드시 사용자가 원문과 대조해 확인하도록 설계했습니다(아래 "시험 현황" 참고).

예시 시나리오 (누르면 자동 입력 후 계산)

① 정액 8만원, 수도·인터넷 포함

광고에 비목만 있고 금액은 없는 흔한 형태. 포함된 항목의 참고 비용과 "추가로 확인할 내역"이 나옵니다. 계량 방식을 모르면 구성은 보류되고, 결과 화면의 "가정하고 보기" 버튼으로 가정을 켤 수 있습니다.

② 공용 10만원 + 공과금 별도 실비

공과금이 관리비 밖(별도 실비)일 때. 10만원에 공과금이 이미 들어 있는 것으로 계산하지 않고, 별도로 부담할 수 있는 항목으로 따로 보여줍니다.

③ 44.9만원, 항목 금액 표기

광고에 전기·수도·가스·인터넷이 각 5만원으로 적힌 경우. 광고 금액과 통계 참고 비용을 나란히 비교합니다. 난방·TV·공용 금액은 이 도구의 계산 범위 밖이라 "광고상 미분류"로 남습니다.

세 예시는 실제 다방 광고 상세보기 화면(2026-10-20 관찰)의 표기 유형을 옮긴 것이며, 특정 매물이 아닙니다.

"정답 카드와 연결 안 되는 틀린 읽기"는 면적·관리비까지 잘못 읽어 어느 카드의 오독인지 알 수 없는 출력 수입니다. 실제 사용에서는 사용자에게 잘못된 카드로 보일 수 있으므로 오류로 간주해야 합니다.

  • 다수결 조합은 이 46카드를 보고 고른 것이라 독립 성능이 아닙니다. 1차 후보는 EasyOCR 단독 + 규칙 파서 + 사용자 확인입니다.
  • 다방 웹 화면 5장만 사용했습니다. 직방·모바일 화면, 관리비 상세보기 화면에서의 성능은 아직 검증하지 않았습니다.
  • 같은 화면의 카드들은 글꼴·배치가 같아 서로 완전히 독립이 아닙니다.

계산 로직 — 전기 요금 구간 경계 등 31개 점에서 독립 재구현과 일치, 안전 규칙 15,309개 조합에서 위반 없음(정의한 6개 규칙 기준), 안전장치를 일부러 망가뜨린 변형 3종 모두 시험이 감지, 이상 입력 11건 처리. 한전 공식 계산기·실제 고지서와의 대조는 아직 못 했습니다.

아직 말할 수 없는 것 — 개별 가구의 실제 공과금 예측 정확도, 서울 원룸 관리비의 정상 범위, 과도한 관리비를 찾아내는 정확도. 실제 고지서와 개인 단위 통계가 있어야 검증할 수 있습니다.
