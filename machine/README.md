# AI 월세 함정 탐지기 — 데이터 분석 모듈

> 이 폴더(`machine/`)는 데이터 분석 담당 영역입니다. 프로젝트 전체 구성은 저장소 최상위 [README](../README.md)를 보세요.
> 아래 설명의 파일 경로는 모두 이 폴더 기준입니다. 최근 추가: 관리비 공과금 참고값(`analysis_internal/utility/`), 광고 이미지·문구 판독 실험(`analysis_internal/extraction/`).

서울시 전월세 실거래 데이터로 "이 월세가 비슷한 조건의 실제 계약 대비 어느 수준인지"를 비교하고, 비교 근거와 신뢰도를 함께 보여주는 분석 코드입니다. 팀 프로젝트에서 **데이터 분석 담당** 부분입니다.

> 이 모듈은 "사기·함정"을 판정하지 않습니다. 실거래 데이터에 없는 옵션·관리비·건물 상태 차이가 있을 수 있어, 가격 위치와 신뢰도, 확인할 항목을 제공하는 참고 도구입니다.

## 구성
| 파일 | 역할 |
|---|---|
| `collect_rent.py` | 서울 열린데이터광장 `tbLnOpendataRentV` 수집(구·연도별) |
| `compare_rent.py` | 정제, 1~3차 유사 거래 탐색, 신뢰도 점수, 백테스트 |
| `analyze.py` | 팀 연동 진입점 `analyze_listing(payload, pool)` (규격: `api_spec.md`, 계약 v1.1: `contract/`) |
| `normalize_listing.py` | 입력 변환 계층(별칭·단위·층·확인 규칙) + 광고 층 문구 분류기, `analyze_raw()` |
| `contract/`, `integration_kit_v1.1/` | 연동 계약 v1.1·상태별 예시 JSON, AI 광고 분석용 준비팩(프롬프트·테스트 템플릿) |
| `run_holdout.py` | 규칙 고정 후 미사용 구(서대문·성북) 홀드아웃 검증 |
| `run_validation.py` | 정제·백테스트·검증표 생성 → `output/validation_report.xlsx` |
| `test_analyze.py`, `test_normalize.py` | 상태·라벨·경고 규칙 테스트(40개), 변환·층 문구 테스트(38개) |
| `check_area_basis.py` | 서울시 면적 컬럼 ↔ 국토부 실거래가 CSV 건별 대조 |
| `sensitivity_detached.py`, `fake_missing_floor.py`, `dup_sensitivity.py` | 단독다가구 층 미확인·중복 의심 민감도 실험 |
| `building_ledger_sample.py` | 건축물대장 표제부(지하층수) 표본 확인(인증키 필요, 아직 미실행) |
| `분석결과_6개구.md` | 결과·한계 전체 기록, `오픈소스_조사.md`, `확인결과_요약.md` |

## 실행
```bash
# 1) 데이터 수집 (서울 열린데이터광장 인증키 필요: 환경변수 SEOUL_API_KEY 또는 --key-file)
python collect_rent.py --key-file key.txt --years 2025 2026 --gu 11620 --out data/rent_gwanak_2025_2026.csv
# 2) 정제 + 백테스트 + 검증표 (data/rent_*_2025_2026.csv 를 모두 읽음)
python run_validation.py
# 3) 분석 함수 / 테스트
python test_analyze.py
```
Python 3.10+, pandas, numpy, requests. 엑셀 출력에는 openpyxl.

## 검증 요약 (관악·광진·마포·동작·강서·노원, 2025~2026, 백테스트 8,995건)
- 비교 가능한 거래가 부족해 보류한 비율 0~0.7%, 중앙 오차 16.7%, 신뢰도 높음 등급 11.9% / 보통 20.0% / 낮음 28.3%.
- 용도별 중앙 오차: 오피스텔 7~14%, 단독다가구 14~19%, 아파트 15~22%, 연립다세대 22~28%.
- 서울시 `RENT_AREA`는 국토부 면적 컬럼과 건별 대조에서 100% 일치(아파트·연립다세대·오피스텔은 전용면적, 단독다가구는 계약면적).
- 단독다가구는 실거래에 층이 없어 지상층 확인 + 신뢰도 높음일 때만 제한적으로 판정(`분석결과_6개구.md` 11~14절).
- 홀드아웃(서대문·성북, 규칙 고정, 통과 기준 사전 설정): 7개 기준 전부 통과. 다만 비교 거래가 얇은 지역은 판정 가능 비율이 낮아짐(45.5%/층 미확인 26.2%)(16절).

## 한계
옵션·관리비·건물 상태는 데이터에 없음 / 6개 구만 검증 / 호수 정보가 없어 중복 여부 판별 불가 / 계약일 이전 거래만 사용했지만 과거 시점의 실제 공개 여부까지 재현한 것은 아님.

## 데이터와 라이선스
- 서울시 부동산 전월세가 정보(서울 열린데이터광장): **공공누리 제1유형(출처표시, 상업적 이용·변경 가능)**, 갱신주기 매일 1회(데이터셋 페이지에서 직접 확인).
  출처 표시 예: "데이터 출처: 서울특별시 열린데이터광장 '서울시 부동산 전월세가 정보'(공공누리 제1유형), 국토교통부 실거래가 공개자료. 본 서비스의 시세 비교와 신뢰도 평가는 팀에서 가공·산출한 결과이며 원자료 제공기관의 공식 가격 판정이 아닙니다."
- 국토교통부 실거래가 공개시스템 CSV는 화면 안내상 법적 효력이 없는 참고용이며, 재배포 조건은 확인하지 않았습니다. 건축HUB 건축물대장정보는 이용허락범위 제한 없음(페이지 표기).
- 원본·정제 데이터는 저장소에 포함하지 않았습니다(`collect_rent.py`로 직접 수집).
- 코드의 라이선스는 아직 정하지 않았습니다(팀 합의 후 `LICENSE` 추가).
