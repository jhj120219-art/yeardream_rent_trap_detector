# 오픈소스·공개 데이터 조사 (2026-10-18)

방법: ChatGPT에 조사를 맡기고(`gpt_opensource_20261018.txt`), 그 주장 중 핵심 저장소는 GitHub API/README로 직접 확인함. 확인 못 한 것은 "미확인"으로 표시.

## 결론
- **우리 비교 로직(1~3차 탐색 + 신뢰도 등급 + 백테스트)을 대체할 오픈소스는 찾지 못함.** 월세 시세 비교를 8,995건 백테스트로 검증해 공개한 코드는 확인되지 않음. 그대로 유지.
- 오픈소스는 주변 기능(데이터 추가 수집, 광고 이미지 OCR, 주소 변환, 경계 계산)에만 쓸 가치가 있음.

## ChatGPT 주장 중 직접 확인하지 못한 것
- PublicDataReader PyPI 최신 배포일(2025-03-03, v1.1.1.post2)과 "건축물대장 엔드포인트 변경 반영"
- 카카오 로컬 API `coord2regioncode`/`b_code` 응답 필드, 행안부 주소 API 갱신일, 서울시 법정동 경계 SHP의 세부 조건
- southkorea-maps의 GADM 자료가 "비상업적만 허용"이라는 설명
- Shapely/GeoPandas 최신 버전·배포일
- 서울시 전월세 데이터·카카오 API 결과의 대량 재배포·장기 저장 허용 범위(ChatGPT도 확정 못 함) → 공개 저장소에 원본 대량 업로드 전 확인 필요

## 채택 우선순위 (ChatGPT 권고 + 우리 확인 반영)
1. 카카오 로컬 API(주소 → 법정동 코드·좌표) — 프론트/백엔드, 오픈소스 아님
2. PaddleOCR — 광고 캡처 20~30장으로 필드별 정확도 측정 후 결정(멀티모달 AI API로 충분하면 생략)
3. PublicDataReader — 국토부 전월세로 **면적 기준 교차 검증**이 필요할 때(공공데이터포털 인증키 필요, 아직 없음)
