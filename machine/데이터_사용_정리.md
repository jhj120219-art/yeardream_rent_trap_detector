## 1. 서울시 부동산 전월세가 정보 (핵심 데이터)
- **수집:** `collect_rent.py`가 `/KEY/json/tbLnOpendataRentV/시작/끝/접수연도/자치구코드` 형태로 구·연도별로 받습니다(한 번에 1,000건). 2025~2026 접수분.
- **이용 조건:** 공공누리 제1유형(출처 표시, 상업 이용·변경 가능), 매일 1회 갱신. 출처: "서울특별시 열린데이터광장 '서울시 부동산 전월세가 정보', 국토교통부 실거래가 공개자료".
- **범위**
  | 용도 | 자치구 | 원본 행 수 |
  |---|---|---|
  | 설계(모델 설계·튜닝) | 강서 100,695 · 관악 85,233 · 마포 79,583 · 광진 70,933 · 동작 66,278 · 노원 59,588 | 462,310 |
  | 1차 검증 | 서대문 50,218 · 성북 50,588 | 100,806 |
  | 최종 독립 평가 | 송파 126,606 · 강북 29,514 | 156,120 |
- **사용한 항목:** 자치구, 법정동, 지번(본번·부번), 층, 계약일, 임대면적, 보증금, 월세, 건물명, 건축연도, 건물용도, 신규/갱신 구분.
- **정제:** 월세 계약만 남기고(전세 제외), 월세 0원·500만원 초과, 면적 5㎡ 미만·200㎡ 초과, 날짜 오류, 4개 용도(아파트·연립다세대·오피스텔·단독다가구) 외를 제외했습니다. 설계 6개 구는 원본 462,310건에서 월세 305,646건이 남았고, 그중 신규 238,074건 · 갱신 58,161건 · 구분 불명 9,411건입니다. **비교에는 신규 계약만 사용**합니다(갱신 제외).
- **확인한 특성:** 단독다가구는 지번과 층이 없습니다(층은 전부 0). 호수 정보가 없어 같은 계약의 중복 여부를 판별하기 어렵습니다. 정답은 실제 체결된 월세이며 광고 호가가 아닙니다.

## 2. 건축물대장 (건축HUB)
- **수집:** `collect_lot_buildings.py`가 지번(시군구, 법정동, 본번, 부번)으로 표제부를 조회해 주건축물(mainAtchGbCd=0) 수를 셉니다. 조회 실패한 지번은 "1동"으로 간주하지 않습니다.
- **조회량:** 설계 데이터 지번 7,707곳(신규 거래 3건 이상) + 최종 평가 지번 1,043곳, 그 외 표본 확인(지번 400곳, 관악구 단독다가구 건물 재고 표본).
- **이용 조건:** 공공데이터포털 표기상 이용허락범위 제한 없음, 개발 계정 일 10,000건.
- **쓰임:** (1) 같은 지번의 건물이 1동일 때만 "같은 건물 비교(0단계)" 사용 (2) 다가구주택의 지하층 비율 추정(약 25%).

## 3. 국토교통부 실거래가 CSV
- 실거래가 공개시스템 자료제공 화면에서 아파트·연립다세대·오피스텔·단독다가구 전월세 CSV를 구·1년 단위로 내려받았습니다(로그인·키 불필요).
- **쓰임:** 서울시 `RENT_AREA`가 아파트·연립다세대·오피스텔은 전용면적, 단독다가구는 계약면적과 건별로 100% 일치함을 확인. 엔진의 가격 근거로는 쓰지 않았습니다.
- **재배포:** 화면 안내상 참고용이며 재배포 조건은 확인하지 못해 저장소에 올리지 않았습니다.

## 쓰지 않은 것
- 조사만 하고 도입하지 않은 자료: 한국부동산원 R-ONE 월세지수, 서울 역사마스터, GIS건물통합정보, 광고 이미지 데이터셋. 광고 호가 공개 데이터와 관리비 기준 데이터는 찾지 못했습니다.
- 이전 문화드림 프로젝트의 서울시 문화행사 데이터는 별개 프로젝트이며 이번 엔진에 쓰지 않았습니다.

## 저장소 공유 방식
- GitHub(비공개)에는 코드, 문서, 요약표만 있고 **원본·정제 데이터는 올리지 않았습니다**(`data/` 제외). 직접 받으려면 본인 인증키로 아래를 실행합니다.
  ```
  python collect_rent.py --key-file KEY.txt --years 2025 2026 --gu 11620 --out data/rent_gwanak_2025_2026.csv
  python run_validation.py
  python collect_lot_buildings.py --key-file HUB_KEY.txt
  ```
- 서울 열린데이터광장 키와 공공데이터포털(건축HUB) 키를 각자 발급받아야 합니다.
