# AI 월세 함정 탐지기 — 데이터 분석 파트 요약 (2026-10-19)

## 1. 한 줄 요약
서울시 전월세 실거래(신규 계약)에서 **비슷한 조건의 거래를 찾아 월세 시세 범위를 보여주고**, 비교 근거가 약하면 **판정을 보류**하는 분석 엔진을 만들고, **처음 보는 두 개 구(송파·강북)에서 사전 등록한 기준 7개를 모두 통과**했다.

## 2. 데이터
| 항목 | 내용 |
|---|---|
| 출처 | 서울 열린데이터광장 `tbLnOpendataRentV`(전월세 신고), 국토부 실거래 CSV(면적 기준 교차검증), 건축HUB 건축물대장(건물 동수) |
| 설계 데이터 | 6개 구(강서·관악·광진·노원·동작·마포), 원본 462,310건 → 정제 후 월세 305,646건(신규 238,074 / 갱신 58,161 / 불명 9,411) |
| 홀드아웃 | 서대문·성북(1차 검증), 송파·강북(최종 평가, 설계에 쓰지 않음) |
| 비교 대상 | 신규 월세 계약만(갱신 제외), 같은 용도·같은 지하 여부끼리 |
| 한계 | 체결가이며 광고 호가가 아님. 단독다가구는 지번이 없음. 층·옵션·역세권 정보 없음 |

## 3. 방법
**비교 단계(자동 전환)**
| 단계 | 범위 | 면적 | 준공연도 | 보증금 | 기간 |
|---|---|---|---|---|---|
| 0 (신규) | 같은 건물(지번) | ±15% | - | ±50% | 24개월 |
| 1 | 같은 동 | ±10% | ±5년 | ±30% | 12개월 |
| 2 | 같은 동 | ±20% | ±10년 | ±50% | 18개월 |
| 3 | 같은 구 | ±25% | 무관 | ±100% | 24개월 |
- 0단계는 중복 제거 후 3건 이상 + **건축물대장상 주건축물 1동**인 지번에서만 사용(다동 단지는 이득이 없었음).
- 비교 사례가 부족하면 다음 단계로 넓히고, 끝까지 부족하면 보류.

**신뢰도 등급**: 비교 건수·가격 분포 폭(Q25~Q75, Q10~Q90)·단계로 "중앙값 오차가 20% 이내일 확률"을 로지스틱으로 계산(구 단위 교차검증), 컷 0.75/0.55로 높음/보통/낮음.

**가격 라벨**: 비교군의 Q25/Q75/Q90 기준(낮은 범위 / 시세 범위 / 다소 높음 / 상위 가격대). 경계 근처(월세를 5% 낮추면 판정이 바뀜)는 보류. 단독다가구·낮음 등급·3차 탐색·0단계 10건 미만은 가장 강한 라벨 금지.

## 4. 핵심 결과
**설계 6개 구 (8,991건)**
| 지표 | 기존 방식 | v2 |
|---|---|---|
| 중앙 상대오차 | 16.67% | **15.38%** |
| 오차 20% 이내 | 57.9% | **60.0%** |
| 신뢰도 AUC | 0.67 | **0.764** |
| "높음" 등급 | 47% 매물, 적중 71% | 25% 매물, 적중 **88.9%** |

**독립 홀드아웃 송파·강북 (2,859건, 1회 평가)**
| 사전 등록 기준 | 결과 |
|---|---|
| 전체 중앙오차(같은 건에서 기존과 비교) | 17.86% → **16.67%** |
| 오차 20% 이내 | 55.0% → 57.1% |
| 등급 단조(높음 > 보통 > 낮음) | 90.2% > 62.4% > 38.1% |
| AUC ≥0.70 / Brier <0.2236 | 0.747 / 0.2040 |
| "높음" 적중률(설계 88.9% 대비 -5%p 이내) | 90.2% (571건, 95% CI 87.8~92.6) |
| 안전 규칙 위반 / 누수 위반 | 0 / 0 |
→ **7개 모두 통과**

**세부(보고용)**: 0단계 적용 600건(21.0%)에서 8.38% → 6.99%(건물 단위 부트스트랩 개선 1.60%p, 95% [0.39, 2.90]). 아파트 20.0% → 16.06%, 연립다세대 23.53% → 22.11%, 오피스텔·단독다가구 변화 없음. 송파 개선 미미(19.35% → 18.71%), 강북 16.67% → 15.00%. 가격 라벨 판정 가능 47.3%. 평균 절대오차 17.0만원, 3만원 이내 23.3%.

## 5. 해본 것 중 채택하지 않은 것
| 시도 | 결과 | 결정 |
|---|---|---|
| 머신러닝(HistGradientBoosting) | 전체 오차 1.5%p 개선, 3차에서만 큼. 규칙+ML 평균은 오히려 악화 | 이번 버전 제외 |
| 소표본 축소추정 | 주변 시세 쪽으로 섞을수록 악화 | 기각 |
| 시점 추세 보정(월별 지수) | 월별 기울기가 불안정, 보정 시 14.29% → 16.83% 악화 | 기각 |
| 확률 재보정(등온/Platt) | Brier 소폭 개선뿐, 등급 분포 크게 변동 | 기각 |
| 보증금 환산(연 4%·6%) | 개선 없음 | 미적용 |
| 신고 지연(30·45·60일) | 기존 규칙 16.67% → 16.90%, 0단계는 적용률 93% 유지 | 영향 작음 |

## 6. 신뢰를 위해 한 일
- 면적 기준을 국토부 CSV와 대조해 확인(아파트·연립다세대·오피스텔 전용면적 / 단독다가구 계약면적).
- 단독다가구 반지하 위험: 사용자가 지상층을 확인한 경우에만 제한적 판정, UPPER_TAIL 금지.
- 사전 등록: 정책·신뢰도 계수·데이터·건물 캐시의 SHA-256과 통과 기준을 평가 **전에** 고정, 평가는 1회, 실패해도 정책을 바꿔 재평가하지 않는 규칙.
- 누수 자동 검사 4종(미래 거래 사용, 절단 풀 동치, 미래 거래 주입, 평가 단위 유일성) 위반 0.
- 매 실행 매니페스트(데이터·정책 해시, 코드 버전, 시드)로 재현 가능.

## 7. 한계와 정직한 표현
- 정답은 **체결가**이므로 "광고 월세가 적정한가"의 정확도가 아니다. UPPER_TAIL은 "유사 거래의 상위 가격대"라는 통계적 의미일 뿐 바가지 판정이 아니다.
- 개선폭은 크지 않다(전체 1.2~1.3%p). 0단계가 적용되는 일부 매물에서 크게 좋아진다.
- 단독다가구(34%)는 지번이 없어 개선이 없고, 다동 지번·표본 부족 매물은 여전히 오차가 크다.
- 월세 평균 오차는 17만원, 3만원 이내 23% — 상대오차 지표보다 체감이 엄격하다.
- 실제 월세가 Q90을 넘는 비율이 명목 10%보다 높은 14~16%인 것은 비교 분포가 새 계약의 개별 편차보다 좁기 때문일 가능성(확정 아님).
- 건물 동수는 현재 건축물대장 기준이라 과거 계약 시점과 다를 수 있다(0단계 사례에서 건축연도 불일치 0건으로 징후는 없음).
