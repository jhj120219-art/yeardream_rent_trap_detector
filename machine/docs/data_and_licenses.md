# 데이터 출처와 이용 조건

API 키와 원본 데이터 파일은 저장소에 없습니다. 아래 데이터는 각자 발급받은 키로 직접 받습니다.

## 저장소에 없지만 계산에 필요한 파일

| 파일 | 내용 | 준비 방법 |
|---|---|---|
| `data/utility_stats/energy_reference_2023.csv` | 가구에너지패널 14차(2023) 결과표를 옮긴 표 (관리비 점검의 참고 사용량) | 재배포 조건 확인 전이라 저장소에 올리지 않았습니다. 같은 파일을 받아 두거나(`ENERGY_REFERENCE_CSV` 환경변수로 위치 지정 가능) KESIS 결과표를 받아 `parse_hep14.py`로 만듭니다. 서울 가구 표만 담은 작은 파일(약 1,000행)로도 동작합니다. 자세한 방법은 `python check_data.py` 출력과 `machine/README.md` |
| `output/clean_rent_data.csv` | 정제된 서울시 전월세 (월세 비교 풀) | `collect_rent.py` -> `prepare_clean_data.py` |

## 저장소에 포함한 것

| 파일 | 내용 | 비고 |
|---|---|---|
| `analysis_internal/utility/tariff_data/tariffs_2026-10.json` | 한전 · 서울도시가스 · 아리수 요금표 | 값마다 출처 · 확인 상태 |
| `analysis_internal/utility/recent_data/recent_seoul_summary.json` | 한전 2025 · 가스공사 2024 서울 집계 요약 | 이용허락범위 제한 없음. 갱신: `utility/recent_load.py` |
| `analysis_internal/utility/recent_data/source_registry.json` | 근거 자료 목록(확인 여부 · 기간 · 단위 · 갱신 주기) | |

## 월세 비교에 쓰는 데이터

| 데이터 | 출처 | 이용 조건 | 받는 방법 |
|---|---|---|---|
| 서울시 부동산 전월세가 정보 | 서울 열린데이터광장 `tbLnOpendataRentV` | 공공누리 1유형(출처 표시, 상업 이용 · 변경 가능), 매일 갱신 | `collect_rent.py` (서울 열린데이터광장 인증키) |
| 건축물대장 표제부 | 공공데이터포털 건축HUB | 이용허락범위 제한 없음, 개발계정 일 10,000건 | 오픈 API (인증키) |
| 전월세 실거래가 CSV | 국토교통부 실거래가 공개시스템 | 참고용, 재배포 조건 미확인 → 저장소에 없음 | 웹에서 내려받기 (면적 기준 대조에만 사용) |

출처 표시 예: "데이터 출처: 서울특별시 열린데이터광장 '서울시 부동산 전월세가 정보'(공공누리 제1유형), 국토교통부 실거래가 공개자료. 본 서비스의 시세 비교와 신뢰도 평가는 팀에서 가공 · 산출한 결과이며 원자료 제공기관의 공식 가격 판정이 아닙니다."

## 쓰지 않는 것

- 다방 · 직방 등 광고 플랫폼의 자동 수집: 약관 확인 전 보류. 광고 캡처는 저장소에 올리지 않으며 2026-11-19까지 삭제합니다.
- 한국부동산원 R-ONE 월세지수 등 조사만 한 자료.

## 한계

체결가 기준 · 6~10개 자치구 검증 · 단독다가구는 지번과 층이 없음 · 관리비 · 옵션 · 건물 상태는 월세 데이터에 없음 · 건물 동수는 현재 대장 기준이라 과거 계약 시점과 다를 수 있음 · 신고 지연으로 최근 거래가 반영되지 않을 수 있음.
