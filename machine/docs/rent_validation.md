# 월세 시세 비교 — 검증 요약

무엇을 어떤 조건에서 확인했는지와 한계를 적었습니다. 상세 실험 기록은 저장소에 두지 않았습니다.

## 평가 조건

- **데이터:** 서울시 부동산 전월세가 정보(신규 월세 계약). 비교 대상은 계약일 이전 거래만 사용.
- **정답:** 실제 체결된 월세. 광고 호가가 아닙니다.
- **지표:** 중앙 오차율(|추정 중앙값 − 실제| / 실제), 오차 20% 이내 비율, 신뢰도 등급별 오차, 판정 가능 비율.
- **구 구분:** 설계(규칙 튜닝) 6개 구 / 1차 홀드아웃 서대문 · 성북 / 2차 홀드아웃 송파 · 강북. 홀드아웃은 규칙 고정 후 사전 통과 기준을 정해 놓고 평가했습니다.

## 결과

| 평가 | 결과 |
|---|---|
| 설계 6개 구 (관악 · 광진 · 마포 · 동작 · 강서 · 노원) 백테스트 8,995건 | 중앙 오차 16.7% · 신뢰도 높음 / 보통 / 낮음 = 11.9 / 20.0 / 28.3% (단조 증가) |
| 용도별 중앙 오차 | 오피스텔 7~14% · 단독다가구 14~19% · 아파트 15~22% · 연립다세대 22~28% |
| 1차 홀드아웃 (서대문 · 성북, 3,070건 호출) | 사전 기준 7개 모두 통과, 전체 중앙 오차 16.7%, 안전 규칙 위반 0 |
| 2차 홀드아웃 (송파 · 강북, 내부 엔진 v2, 1회) | 사전 기준 7개 모두 통과, 전체 중앙 오차 17.86 → 16.67%, 20% 이내 55.0 → 57.1% |
| 면적 기준 | 서울시 `RENT_AREA`는 국토부 면적과 건별 100% 일치 (아파트 · 연립다세대 · 오피스텔은 전용면적, 단독다가구는 계약면적) |

## 한계 · 주장하지 않는 것

- "시세보다 비싸다 = 함정"이라고 판정할 수 없습니다. 중앙 오차가 15~17%라서 가격 위치와 범위(사분위), 신뢰도, 확인할 항목만 제공합니다.
- 판정 가능한 비율은 지역에 따라 낮아집니다. 비교 거래가 얇은 구에서는 층을 확인해도 약 45%, 층을 모르면 약 26%였습니다.
- 단독다가구는 실거래에 층이 없어, 지상층을 사용자가 확인하고 신뢰도가 높을 때만 "높은 편" 이하로 제한적으로 판정합니다.
- 6~10개 자치구, 2025~2026 기간만 검증했습니다. 옵션 · 관리비 · 건물 상태는 데이터에 없어 오차 원인을 분리하지 못했습니다.
- 송파 · 강북 홀드아웃은 한 번 평가했으므로 소진되었습니다. 이후 규칙을 바꾸면 새 홀드아웃이 필요합니다.
