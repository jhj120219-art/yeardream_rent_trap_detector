## 6. 해석과 한계
- 중앙 오차 16.7%는 "시세보다 몇 만 원 비싸다"만으로 함정을 단정하기엔 큼. 신뢰도 "높음"이고 분포 상위(Q90 초과)일 때만 "비싼 편"을 표시하고, 항상 IQR 범위를 함께 보여주는 것이 적절.
- 이 모델은 "같은 조건 실거래 대비 얼마나 높은가"만 판단함. 옵션·관리비·인터넷·엘리베이터·건물 상태·사기 위험은 알 수 없음.
- 6개 구만 검증(서울 25개 중). 비교 풀은 신규 월세 계약이며 호가가 아님.
- 아직 안 한 것: 나머지 19개 구, 광고 전용면적과 임대면적(RENT_AREA)이 같은 기준인지 확인, 인접 동 기준 3차 확대(현재는 같은 구 전체), 웹앱 연동 테스트.

## 7. ChatGPT 검토 결과와 반영 계획 (`gpt_review_20261018.txt`)
- 판정 표현: 신뢰도 높음 + Q90 초과일 때만 "유사 거래 대비 높은 가격대"로 표시, Q75~Q90은 "상위 가격 구간", 신뢰도 보통은 "추가 확인 필요", 낮음은 가격 판정 보류. Q90 초과는 부당 가격이나 사기의 증거가 아니므로 "함정 발견"이라고 쓰지 말고 "추가 비용·매물 조건 확인 권장"으로 연결. 서비스 이름은 유지하되 개별 판정에는 "함정"을 쓰지 않음. "중앙 오차 11.9%"는 "이 집이 ±11.9% 안"이라는 뜻이 아님(높음 등급의 절반 정도가 그 이하라는 통계, 20% 초과 오차도 29.3% 있음).
- 연립다세대: 제외하지 않고 등급별로 판정을 제한(높음만 제한적 판정, 낮음은 보류, 3차는 항상 참고용) + 경고 문구. 단독다가구: 층 0은 "층 미확인"으로 처리하고 지상으로 간주하지 않음 → 가격 판정 보류 권고. 건축물대장 연동은 이번 범위 밖.
- 면적: RENT_AREA는 임대면적이라 광고의 전용·공급면적과 같은 기준인지 확인이 선행. 확인 전에는 `AREA_BASIS_UNVERIFIED`로 가격 판정 보류. 3차 확대는 이번에는 같은 구 전체 유지(문구로 한계 명시), 지원 범위 밖 19개 구는 `OUT_OF_SCOPE`.
- 상태값 제안: status = COMPARED / REFERENCE_ONLY / INSUFFICIENT_DATA / INPUT_REVIEW_REQUIRED / OUT_OF_SCOPE, price_label = UPPER_TAIL / UPPER_RANGE / TYPICAL_RANGE / LOWER_RANGE / UNRATED. 최종 status는 분석 코드가 결정(핵심 경고가 있으면 REFERENCE_ONLY로 강등).
- 우선 작업 3개: (1) 집계 검산·중복 플래그가 결과에 주는 영향 검증 (2) 주택 유형별 판정 규칙 검증(등급 × 단계 × Q90 초과) + 검증에 쓰지 않은 최근 기간 확보 (3) 팀 연동용 입력·출력 규격 확정.
- 검증 한계로 명시: 계약일 이전 거래만 사용했지만 과거 시점에 실제로 공개되어 있던 데이터까지 재현한 것은 아님(신고·공개 시차).
- 집계 검산: ChatGPT가 지적한 "합계 불일치"는 정제 전·후 기준을 섞어 쓴 표 때문이었고(4개 구 중간 값을 6개 구로 잘못 옮긴 오류 포함) 정정함. 등급별 건수 합계 8,991은 백테스트 8,995건 − 비교 부족으로 보류된 4건.

## 8. 중복 의심 행 민감도 분석 (`dup_sensitivity.py`, ChatGPT 설계 검토 반영)
설계: 비교 풀에서만 동일 조건 행(구·동·용도·지번·층·계약일·면적·보증금·월세·신규/갱신 동일)을 1건으로 통합(B안)하고, 백테스트 대상 8,995건은 A안(그대로)과 동일하게 유지. 풀 행 수 305,646 → 217,275(88,371행, 28.9% 통합).

| IQR 안(기대 50%) | 50.25% | 50.12% |
| 1차 / 2차 / 3차 | 65.3 / 27.7 / 7.0% | 63.8 / 26.9 / 9.1% |

| 비싼 편 / 다소 높음 | 12.0 / 12.1% | 11.3 / 11.9% |

- 용도별(단독다가구·연립다세대·오피스텔·아파트) 중앙 오차 차이도 0.1~0.4%p로 거의 같음.
- 같은 매물의 판정 라벨이 바뀐 비율 8.2%(737/8,986), 신뢰도 등급이 바뀐 비율 9.3%, 탐색 단계가 바뀐 비율 3.6%. "비싼 편" 여부 자체가 바뀐 매물은 1.7%(153건). 라벨 변경의 대부분은 비교 건수가 줄어 신뢰도가 낮음으로 내려가면서 "참고만"으로 바뀐 경우.
- 결론: 통합해도 정확도는 개선되지 않고(16.67%→16.67%) 비교 사례만 줄어 3차 확대·신뢰도 하락이 늘어남 → **중복 의심 행은 삭제하지 않고 그대로 사용(A안), 플래그만 유지**. 이는 "동일 조건 행이 실제로는 서로 다른 호실의 별도 계약일 가능성"과 일치하지만 증명은 아님(호수 정보 없음).

## 11. 단독다가구 층 미확인 민감도 실험 (`sensitivity_detached.py`, 2026-10-18)
목적: 단독다가구는 층이 전부 0이라 지하·반지하와 지상 계약이 섞여 있음. 그 때문에 가격 라벨이 얼마나 뒤집히는지 본다. **판정 안정성 테스트이며, 단독다가구의 실제 층 효과·오판율을 측정한 것이 아님.**
통과 기준은 실험 전에 정함: 지하 비율 20% 가정 시 지상 매물의 비교 편향(+p×d)만큼 분포를 이동해도, 기준 UPPER_TAIL의 70% 이상이 "높은 편 이상(UPPER_TAIL/UPPER_RANGE)"을 유지하면 안정.

### (A) 지하 할인율의 근거: 연립다세대(층 정보 있음)
지하(-1층) 신규 월세 1,513건 중 같은 동·면적 ±20%·보증금대·직전 12개월의 지상층(≥1층) 비교 5건 이상인 1,268건:

- 한계: 다가구가 아니라 연립다세대의 값이며, 지하 단위의 면적·상태 차이를 통제하지 못함.

### (B) 비교 분포를 이동시킨 결과 (단독다가구 3,865건; 이동 = 실제 비교 대상이 현재 비교군보다 몇 % 비싼가)
| 이동 | 라벨 변경률 | 기준 UPPER_TAIL(203건) 유지 | 그중 "높은 편 이상" 유지 | 기준 "높은 편 이상" 전체 유지 |
|---|---|---|---|---|
| +5% | 14.4% | 76.4% | 99.5% | 84.3% |
| +10% | 26.7% | 46.8% | 92.6% | 60.0% |
| +15% | 37.3% | 36.0% | 77.3% | 46.9% |
| +20% | 44.1% | 19.7% | 56.2% | 33.5% |
| +30% | 56.7% | 10.8% | 29.6% | 19.7% |
- 사전 기준 평가: 지하 20% 가정 → 이동 +5.7% → 기준 UPPER_TAIL의 **99.5%가 "높은 편 이상" 유지 → 통과**. 신뢰도 높음·전체 모두 동일. 같은 기준이 깨지는 지하 비율은 대략 **55% 이상**(이동 +15~16%에서 70% 미만).
- 그러나 **최상위 라벨(UPPER_TAIL, 상위 10%) 자체는 불안정**: +5%에서 76%, +10%에서 47%만 유지. "높은 편(UPPER_RANGE)"까지 포함하면 안정적.
- 반대 방향(실제 비교군이 더 쌈, 지하 매물): 이동 -20%에서 "경고 없음이던 매물의 54%"가 새로 경고 대상 → 지하 매물은 시세 범위로 나와도 실제로는 비쌀 수 있는 **놓침 위험**(과소 경고). 지하 월세가 낮아 '낮은 편'으로 보이는 쪽은 사용자에게 해롭지 않은 방향.
- 참고(다른 용도, 같은 이동 방식): 오피스텔은 +10%에서 UPPER_TAIL 26%만 유지(분포가 좁아 더 민감), 아파트 46%, 연립다세대 61%. 분포가 좁을수록 같은 이동에 더 민감함.
- 기준 라벨 분포(단독다가구, 판정 허용 가정): 시세 범위 45.7%, 낮은 편 17.2%, 높은 편 17.1%, 비싼 편 5.3%, 판정 안 함 14.7%.

- 정책 선택지: (B) 가격 범위만 제공 유지 / (C-lite) 사용자가 "지상층"이라고 확인한 경우에 한해 최대 UPPER_RANGE("높은 편")까지만 허용하고 UPPER_TAIL은 금지, 반지하·층 모름은 범위만 제공. 이 결정은 사용자·팀 합의 필요(아직 코드에는 반영하지 않음).

### 가짜 결측 실험 (`fake_missing_floor.py`, ChatGPT 제안)
연립다세대(층 정보 있음) 신규 월세 중 최근 3개월 기준 매물 3,538건(지하 123)에서, 1·2차 탐색에서 정답(같은 층 유형 비교군)과 가림(지하·지상 혼합 비교군) 모두 10건 이상인 3,160건(지상 3,097·지하 63)을 사용. 지하 비율 p는 가중치로 인위 조정(자연 비율은 비교군의 평균 2.7%).
정답 라벨은 같은 층 유형끼리만 만든 분포의 Q75 초과 여부. 오경고율(FDR) = 가림 분포에서 "높은 편"이라 했지만 정답은 아닌 비율.

**지상층 매물 (3,097건 · p별 378건)**: 오경고율 FDR % / 경고율 % / 재현율 %
| 정책 | p 자연(2.7%) | p=10% | p=20% | p=30% | p=50% |
|---|---|---|---|---|---|
| C-lite: Q75 초과 | 1.1 / 27.5 / 95 | 5.8 / 31.7 / 98 | 11.1 / 33.3 / 97 | 17.8 / 35.7 / 97 | 32.5 / 42.3 / 94 |
| F(+10%): Q75×1.10 초과 | 0.6 / 20.5 / 71 | 3.3 / 24.1 / 77 | 6.1 / 25.9 / 80 | 10.8 / 29.4 / 86 | 25.9 / 36.8 / 90 |
| F(+15%): Q75×1.15 초과 | 0.0 / 17.9 / 63 | 0.0 / 20.6 / 68 | 1.2 / 22.0 / 71 | 10.3 / 25.7 / 76 | 22.8 / 32.5 / 83 |
| 강한 라벨: Q90 초과 | 0.8 / 12.8 / 88 | 3.8 / 14.0 / 86 | 7.1 / 14.8 / 88 | 19.4 / 17.7 / 92 | 33.7 / 22.0 / 93 |

- 핵심: **지하 비율이 낮으면(≈10% 이하) 층을 모르고 비교해도 오경고율이 6% 이하로 낮고**, 20%에서 약 11%, 30%에서 약 18%, 50%에서 약 33%까지 오른다. 필요한 안전 수준은 실제 p에 달려 있고 p는 모름.
- F(+10%)는 오경고율을 C-lite의 절반 수준(p=20%에서 11.1% → 6.1%)으로 줄이지만 경고 건수가 약 20~25% 줄고 재현율이 낮아짐(자연 p에서 95% → 71%). F(+15%)는 p≤20%에서 오경고율이 사실상 0~1%이나 재현율 63~71%.
- 지하 매물(63건뿐, 정답 기준 높은 편 약 13건)은 어떤 정책에서도 재현율 8~43%로 낮음: 지하 매물이 비싼데도 혼합 비교군에서는 시세 범위로 보여 놓치는 위험. 표본이 작아 방향만 참고.
- 한계: 연립다세대와 단독다가구는 다른 집단이며, 정답 라벨도 Q75 문턱 근처에서는 흔들려 오경고율에는 경계선 사례가 포함됨(실제 오판보다 보수적으로 과대 계산될 수 있음).

## 13. 단독다가구 조건부 판정 정책 반영 (2026-10-19)

- 정책 영향: 단독다가구 조건부 판정(지상층 확인 + 높음 + F+10%)을 유지. 지하 비율이 약 25%로 추정되어 "층 모름 + 판정"은 계속 금지하는 것이 타당.
