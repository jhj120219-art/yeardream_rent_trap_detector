## 사용 방법
링크를 열면 자동 연결됩니다. 접속키 입력 없이 직접 입력 → 확인 → 분석 → 결과 조회가 가능합니다.
집 PC의 기존 API(8012)·DB는 유지하고, 공개 화면·중계만 8013에 별도로 실행했습니다.
키는 집 PC의 기존 비공개 team-access.key에서 서버가 읽습니다. 프론트·응답·PPT·Git에 키를 넣지 않았습니다.

## 구성과 검증
- backend/web: 팀 프론트 main c6fda9f 기준 화면의 공개 체험 빌드. 자동 연결 및 키 없는 요청만 보완했습니다. 원본 frontend/는 변경하지 않았습니다.
- backend/app/public_gateway.py: 같은 주소의 허용된 API 요청만 기존 로컬 분석 서버로 중계합니다. 팀 키는 서버에서 추가합니다. 세션 토큰을 통한 사용자 자료 분리는 기존 API가 유지합니다.

## 재시작과 제한
기존 API가 먼저 실행 중이어야 합니다. 집 PC의 기존 비공개 runtime으로 python -m backend.scripts.public_demo --runtime <기존runtime> 실행 시 새 공개 터널을 만듭니다. 현재는 이미 실행 중이므로 중복 실행하지 마세요.
집 runtime/public-connection.json에 현재 주소와 해당 프로세스 ID가 저장됩니다. 키 내용은 출력하지 마세요.
공개 체험만 중지하려면 집 runtime에 public-stop.request를 생성합니다. 다시 시작하기 전 그 요청 파일만 제거하고 공개 프로세스가 끝났는지 확인하세요. 기존 API나 DB를 종료할 필요는 없습니다.
임시 trycloudflare 주소라 공개 중계 재시작 후 주소가 바뀔 수 있습니다. 집 PC·기존 API·공개 중계가 켜져 있어야 합니다. 고정 도메인·상시 운영 구성은 별도입니다.
