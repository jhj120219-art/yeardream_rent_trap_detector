## 사용자 선택이 필요한 차이

### D1 · 관리비 입력
014번: 총액만, 포함 항목 입력 없음. 시트 하단 메모: 포함 체크박스. 기존 논의·코드: 5항목 포함/별도/모름·명시 금액.
A 총액+5항목 상세 유지 / B 총액만 / C 총액+포함 체크만
사용자 선택 대기. 현 코드·DB 변경 없음

### D2 · 비용 결과
034·035번: 공과금·인터넷별 예상 금액 및 두 종류 합계. 현재 서버: 추정 계산 보류·필수 CSV 누락. 두 합계의 비용 범위도 다를 수 있음.
A 확보 후 두 금액을 별도 표시, 차액·%는 월세에만 / B 월세+광고 관리비 우선, 예상 비용은 후속
사용자 선택 대기. 합계 차이를 높음/낮음 판정에 사용하지 않음

### D3 · 지원 범위
002번: 서울/전국·아파트/전체 유형 협의 중. 현 코드는 확보·검증된 범위만 연결.
A 현재 검증된 범위 / B 서울 전체 목표+미확보 안내 / C 전국 확대 계획
사용자 선택 대기. 데이터 없는 곳을 지원 완료로 표시하지 않음

### D4 · 입력 단계
기존 시안 5개 화면에는 주소 검색 시작·조회값 읽기 전용·값 출처 표시가 빠짐. 정의서는 4단계.
정의서의 4단계로 수정. 관리비는 3단계 안의 입력 묶음
보고서·새 화면 그림 반영. 실제 프론트 구현은 별도

### D5 · 주소 직접 입력
011번: 직접 입력 선택에서도 주소는 검색 선택. 현재 주소 API 미설정·오류 시 직접 입력 대체 제공.
A 검색 선택 필수+실패 시 잠시 중단 / B 검색 우선, 실패 시 코드 검증된 직접 입력 허용
사용자 선택 필요. 대체 경로 임의 삭제하지 않음

### D6 · 건물 조회·연도
006·010·017번: 건축물대장 조회·주소 변경 갱신·출처 충돌 안내. 015번: 사용승인연도를 건축연도로 쓸지 협의 중.
기능 연결 필요. 연도는 명시적 매핑 합의 전 자동 대입하지 않음
분석·백엔드 협의 항목. 조회 구현 완료로 보고하지 않음

### D7 · 참고용 결과
026·028·031번: 참고용·구 전체 확대 결과는 높고 낮음 판정 금지. 기존 시안의 차액 강조 규칙은 상태별 제한 설명이 부족.
정의서에 맞춰 참고용은 중립 수치·이유, 비교 완료일 때만 방향 문구·색상
시안 반영. v2 실제 구 확대 응답에서 판정 억제 재검증 필요

### D8 · 개별 거래 목록
기존 기획은 거래별 목록을 요구. 정의서 027번은 조건·건수·기간을 요구하며 개별 거래 목록은 명시하지 않음. 현재 분석 응답도 목록 없음.
A MVP는 조건·건수·기간만 / B 개별 목록을 추가 요구사항으로 유지
사용자 선택 필요. 가짜 목록 생성 금지

### D9 · 진행률
이전 45%는 임의로 묶은 시연 체크 20개 기준. 정의서 전체 35개와 분모가 다름.
35개 요구사항을 구현·집 배포·실제 화면 검증으로 나눠 대조 후 비율 산정
공식 전체 진행률 산정 보류. 기존 45%를 전체 개발률로 사용하지 않음
