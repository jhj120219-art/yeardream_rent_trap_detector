## 새로 확인한 분석 출력 차이

실제 기준 CSV·분석 코드를 합성 입력으로 실행: 체크 WATER/INTERNET/OTHER, 미체크 ELECTRICITY/GAS. 충분한 계산 조건(1인·10월·개별가스·가스사용 확인·개별계량)을 넣었어도 utility_estimates에는 WATER/INTERNET만 반환됨.

- OTHER 참고값은 근거가 없어 미제공.
- 미체크 ELECTRICITY/GAS는 현재 분석 반환 목록에 없음. 이 실행에서는 조건 부족으로 계산 보류된 것과 구분해야 함.
- backend는 이를 임의 생성·별도 납부로 바꾸지 않고 null로 보존함. 따라서 '체크/미체크 참고비용 전체 표시 완료'라고 보고할 수 없음.
- 분석 담당 요청: 고객 선택을 바꾸지 않은 채, 포함 여부와 독립적으로 계산 가능한 4개 공과금의 참고값·보류 사유를 반환하는 출력 확장이 필요함. 기타는 계속 미제공 가능. 분석 정책·machine 코드는 임의 수정하지 않음.
- 익명 강서 2건·송파 1건의 실제값·산정값·오차·방식 선택 결과는 최신 팀 문서에서 확인하지 못함. 운영 계산은 비활성화 유지.
