# 팀 저장소 백엔드 반영 — 2026-10-20

- 팀 기준: 5c79824. 개인 백엔드 기준: 99796ea.
- 개인 저장소의 Git 관리 대상 backend 파일만 반영했다. 가상환경·DB·원본/정제 거래 데이터·키·ZIP·PC 설정 파일은 제외했다.
- 팀 분석 소스는 machine/ 원본을 직접 사용한다. backend/__init__.py에서 분석 모듈 경로를 연결하고 이미지 프롬프트 경로와 Docker 파일을 팀 구조에 맞췄다. 프론트·machine 원본은 수정하지 않았다.
- 기존 frontend_api_example.js는 최신 .mjs 모듈을 다시 내보낸다. 프론트 전달문은 최신 안내로 갱신했다. 기존 브리핑·JSON 예시는 삭제하지 않고 과거 기록으로 명시했다.
- 현재 제품 범위: 동네 월세 비교. 같은 건물 우선 비교·관리비는 보류한다.
- 팀 폴더에서 독립 MySQL을 포함한 백엔드 검사 169개와 JavaScript 연결 검사 2개 통과. 기존 분석 기대값은 유지했으며 파일 경로 검사는 팀 machine/ 원본을 실제 사용하는지 검사하도록 맞췄다.
- Docker 이미지 빌드는 이 PC에서 미검증이다. 실제 프론트 화면 연결·상시 서버 배포는 별도 작업이다. 데이터와 키가 없는 새 PC에서 자동으로 분석이 준비되는 것은 아니다.
