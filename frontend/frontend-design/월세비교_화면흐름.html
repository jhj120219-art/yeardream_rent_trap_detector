자동 입력 경로 · 연결 검증 전

주소 검색 API는 실제 외부 호출 미검증입니다. 유형·준공연도 자동 조회는 별도 협의가 필요합니다.

이미지 8MB · 전체 요청 9MB 제한. JPG·PNG·WebP는 형식 제안입니다. 이 시안은 내용을 읽거나 전송하지 않습니다.

현재 전달된 지원 지역: 강서·관악·광진·노원·동작·마포구. 실제 서비스에서는 지원 범위 API 응답을 사용합니다.

내 매물 · 설계 후보
MVP 포함 여부는 논의 중입니다. 이 목록은 페이지 메모리의 시연 자료로, 실제 서버 목록이 아니며 새로고침하면 사라집니다.
실제 DELETE /sessions/current는 저장 자료도 모두 삭제합니다. 창을 닫을 때 자동 호출하지 않습니다.




팀 연동 기준과 남은 논의
실제 연동: 팀 접속키 입력 → POST /sessions → 지원 범위 확인 → POST /listings → POST /listings/{id}/analyses → GET /listings/{id}/report.
모든 실제 요청에 X-Team-Key, 세션 이후 Bearer 토큰 사용. 결과는 property.input / rent.result. 키는 소스·로그·배포 파일에 넣지 않습니다. 이 시안은 키를 받지 않습니다.
